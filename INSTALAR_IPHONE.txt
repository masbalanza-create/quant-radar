QUANT RADAR · IPHONE Y DESPLIEGUE

1. Conecta este repositorio a un servicio web Python que sirva la interfaz
   y la API bajo la misma URL HTTPS. Usa pip install -r requirements.txt como
   instalación y python server.py para arrancar.
2. El proveedor define PORT. Configura QR_ACCESS_PASSWORD con al menos 16
   caracteres. El usuario de acceso es radar. Las claves de Alpaca y OpenAI
   son opcionales. Configúralas en las variables privadas del servicio.
3. Para habilitar el DCF con datos revisados, configura QR_VALUATION_INPUTS
   con la ruta de un archivo privado legible por el servidor. Consulta
   docs/valuation.md para su formato. El análisis semanal funciona sin él.
4. Abre la URL HTTPS en Safari en el iPhone, toca Compartir y añade la web a
   la pantalla de inicio. Para obtener cotizaciones, abre la app con conexión.
