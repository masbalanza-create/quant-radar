# Entrenamiento y evaluación

**Entrenamiento de IA** es una pestaña reservada. Las decisiones actuales son reglas explícitas documentadas en [Arquitectura](architecture.md). La función de OpenAI explica el contexto cuando se solicita.

1. Define el horizonte, universo, referencia y resultado que se quiere predecir. Cada estrategia conserva su propia ventana de evaluación.
2. Registra fuente, activo, intervalo, disponibilidad temporal, ajustes y versión. Para valoración, usa los documentos y el perfil revisado disponibles en cada fecha.
3. Separa ajuste, validación y prueba en orden cronológico. Evita que las ventanas de las etiquetas se solapen entre tramos.
4. Compara las reglas actuales y el modelo nuevo con fechas, costes, tamaños y restricciones equivalentes. Registra rentabilidad neta, cobertura, operaciones y pérdidas máximas.
5. Registra predicciones en simulación antes de plantear su integración. Documenta semilla, versión, resultado y límites por mercado y horizonte.
